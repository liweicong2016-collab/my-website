DeepInfer 开源：降本军备赛进到引擎层，但线上全家桶还没交出来

支撑 V4.1-Flash 的离线推理核和协议层开了，编解码能对齐官方 API。KV cache、Prefill/Decode 分离、多副本负载均衡没放；硬件白名单只有 NVIDIA SM100 与昇腾 950。

2026-10-21 ~8 min read 基于 2026-10-20 公开仓库 / 官方定价核验
DeepSeek DeepInfer 推理引擎 昇腾 950 开源
名称说明：流通稿里的「Deepinfra」是口误，指的是 DeepSeek 推理框架 DeepInfer。下文一律用正式名。

结论

  • DeepSeek 把支撑 V4.1-Flash 线上服务的离线推理核 DeepInfer（Apache-2.0）和协议层 deepseek-recipe（MIT）开源了。对私有化最值钱的，是和官方 API 同款的编解码对齐。
  • README 写得很实在：KV cache 系统、Prefill/Decode 分离、多副本负载均衡没放。硬件白名单只有 NVIDIA SM100 与 华为昇腾 950。
  • $0.15 / $0.6 是闲时 cache miss 价，不是全日统一价。真正拉开账单的是 cache hit。
  • 一句话：降本军备赛进入开源引擎阶段；缺的三块基建才是完整线上形态。

1发生了什么

全网还在猜 V4.1 Flash 如何把每百万 token 输入压到约 $0.15、输出约 $0.6 时，DeepSeek 自己掀了底牌：用开源仓库交出生产推理路径里可复用的那一层。交出来的是两件东西，角色不一样，协议也不一样。

仓库协议角色
deepseek-ai/DeepInfer Apache-2.0 离线推理引擎：优化算子、分布式推理、投机解码、SWA Bounded Replay、结构化输出等
deepseek-ai/deepseek-recipe MIT（不是 Apache） 协议转换 + prompt / tokenizer。不跑推理，对齐官方 API 行为

定位要分开读

  • README 写它 powers production services，但开源交付物明确是 offline inference。
  • 媒体转述「后续新模型推理代码会持续合入」——README 无此句。当软承诺，勿当 SLA。

2定价：别把闲时价当成牌面

官方 API Pricing（deepseek-flash / V4.1-Flash）把价格拆成闲时、高峰，以及 cache 命中与否。传播层常说的那组数字，只覆盖其中一格。

口径输入输出
闲时 · cache miss$0.15 / 1M$0.60 / 1M
高峰$0.30$1.20
闲时 · cache hit~$0.003—
$0.15闲时 cache miss · 输入 / 1M
$0.60闲时 cache miss · 输出 / 1M
~$0.003闲时 cache hit · 输入 / 1M
$1.20高峰 · 输出 / 1M

工程上真正吃账单的三项

传播层常把「$0.15 / $0.6」说成统一价。Agent 账单真正吃的是 cache-hit 率 × 峰谷窗口 × 工具调用轮次。真正杀招是 cache hit，不是把闲时 miss 价当成全日牌面。

3README 里最该看的边界

已开源的功能属实：高性能算子、Attention DP/CP、MoE EP+EPLB、DSpark 投机解码、SWA bounded replay、异步调度、batch-invariant、结构化输出等。边界比功能清单更重要——README 把三块线上基建明确留在仓库外面。

内容状态
高性能算子、Attention DP/CP、MoE EP+EPLB已开源
DSpark 投机解码、SWA bounded replay已开源
异步调度、batch-invariant、结构化输出已开源
KV cache 系统明确未开源
Prefill / Decode 分离部署明确未开源
DP 多副本负载均衡明确未开源

硬门槛：仅认 NVIDIA Blackwell SM100 与华为 Ascend 950（CUDA 13 / CANN 9.2）。模型仅限 DeepSeek-V4.1-Flash。消费级卡免谈。

对谁有用。私有化团队优先吃的是 recipe：它抹平「本地服务 vs 官方 API」的格式与工具调用温差，这比再吹一遍开源口号更值钱。单卡开发者不必凑部署热闹，继续调几毛钱官方 API，比自己搭集群划算。

4产业信号：推理先于预训练，再一次被写进白名单

硬件白名单把 SM100 与昇腾 950 并列进第一梯队生产路径。这和此前野村专家纪要、Bloomberg 等公开口径同向：国产加速器在推理 / Serving 渗透快于大规模预训练。

这句话能写到哪一步

  • 大训仍偏 Nvidia 的叙事未被推翻。
  • 适配订单应跟 Serving、算子、recipe。
  • 别写成「已替代预训练」。

这与 2026-09-30 DeepSeek 开源昇腾六大基础组件（TileLang / DeepGEMM-Ascend 等）是同一条「亲写底层」曲线：模型厂向下定义算力软件栈，芯片厂跟着工程现实走。组件那一次的拆解见 DeepSeek 开源昇腾基础组件。

降本军备赛进到开源引擎这一层。完整线上形态，仍然取决于 README 写明没放的三块：KV cache、Prefill/Decode 分离、多副本负载均衡。
